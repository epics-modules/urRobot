# Generated Headers

These headers are generated by cmake during the upstream ur_rtde build
process. They must be updated manually when the ur_rtde submodule is
updated.

To regenerate, configure ur_rtde with cmake and copy the generated headers:

    cd rtdeSrc/ur_rtde
    cmake -B build -DPYTHON_BINDINGS=OFF -DEXAMPLES=OFF
    cp include/ur_rtde/rtde_export.h ../generated/ur_rtde/
    cp include/ur_rtde/rtde_control_script.h ../generated/ur_rtde/
